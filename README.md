# Site sobre Arctic Monkeys

Atividade sugerida em aula com o objetivo de estudar CSS e suas tecnologias. Ela consistia em escolher um artista ou banda e criar um site aplicando o conteúdo passado em aula.
No caso deste projeto, a banda escolhida foi Arctic Monkeys.
